# LibSecret D-Bus Code Generation

The `secrets.DBus.cs` file is auto-generated by the [Tmds.DBus.Tool](https://github.com/tmds/Tmds.DBus) `dotnet-dbus` codegen command. Do not edit it manually, as changes will be lost on re-generation.

## Installing the tool

```sh
dotnet tool install --global Tmds.DBus.Tool
```

## Files

- `secrets.DBus.cs` — Generated D-Bus proxy classes for the [freedesktop Secret Service API](https://specifications.freedesktop.org/secret-service-spec/latest-single/).
- `org.freedesktop.Secret.Prompt.xml` — D-Bus introspection XML for the `org.freedesktop.Secret.Prompt` interface. This file is needed because Prompt objects are created dynamically at runtime and do not appear in the service's introspection data, so the tool cannot discover them from the live bus.

## Regenerating the code

Run the following command from this directory:

```sh
dotnet-dbus codegen --protocol-api --service org.freedesktop.secrets --namespace secrets.DBus org.freedesktop.Secret.Prompt.xml --output secrets.DBus.cs
```

This introspects the live `org.freedesktop.secrets` D-Bus service on the session bus and merges it with the `org.freedesktop.Secret.Prompt.xml` file to produce the complete set of proxy classes.

> **Note:** A running secret service (e.g., GNOME Keyring or KWallet) must be available on the session bus for the introspection to work.
